# منصة وِصَـــال (WISAL) — ربطك بخدمات الحرم المكي الشريف

> مشروع تخرج جامعي: منصة رقمية (موقع + تطبيق جوال) تربط قاصدي المسجد الحرام من معتمرين وزوار بمقدمي خدمات مساندة مؤهلين من أبناء مكة المكرمة.

## 🌟 نظرة عامة

**وصال** تساعد زوار المسجد الحرام في الوصول لخدمات مساندة موثوقة:

- **المرافقة والإرشاد:** توجيه مسارات الطواف والسعي ومرافقة المعتمرين خلال المناسك.
- **مساعدة كبار السن:** مرافقتهم ومساعدتهم في الكراسي المتحركة والأدوار المخصصة.
- **الترجمة والمساعدة اللغوية:** للزوار الناطقين بالإنجليزية والأردية والتركية وغيرها.
- **المساعدة والتنقل:** توجيه التنقل بالعربات الكهربائية والجسور.
- **الدعم والمساندة:** مساندة العائلات والأطفال وذوي الاحتياجات الخاصة.

## ✨ مميزات المنصة

### للمستفيد (زائر الحرم)
- تصفح الخدمات والبحث والتصفية حسب التصنيف والسعر والتقييم.
- حجز خدمة (التاريخ والفترة ونقطة الالتقاء) ومتابعة حالة الحجز أو إلغاؤه.
- **محادثة خاصة** مع مقدم الخدمة داخل كل حجز لتنسيق الموعد ومكان اللقاء.
- تقييم الخدمة بعد اكتمالها (من 1 إلى 5 مع تعليق).
- قائمة المفضلة، وتعديل الملف الشخصي.

### لمقدم الخدمة
- لوحة تحكم بالحجوزات الواردة.
- إضافة الخدمات وتعديلها وحذفها.
- قبول الحجوزات وتأكيدها وتسجيل إتمامها أو الاعتذار عنها.
- المحادثة مع المستفيد داخل الحجز، وتعديل الملف المهني.

### عام
- صفحة **"تواصل معنا"**: الرسائل تُحفظ في قاعدة البيانات وتصل لبريد الفريق `wesal.support.team@gmail.com`.
- واجهة عربية كاملة (RTL) ومتجاوبة مع الجوال.
- **جميع البيانات من قاعدة البيانات**، والموقع والتطبيق يستخدمان نفس الـ API ونفس القاعدة.

## 🏗️ البنية التقنية

```
        الموقع (React)  ──┐
                          ├──►  PHP API  ──►  قاعدة بيانات MariaDB
  التطبيق (Flutter)  ─────┘
```

| الجزء | التقنيات | الاستضافة |
|---|---|---|
| الموقع | React 18 + TypeScript + Vite + Tailwind CSS | Vercel |
| واجهة البرمجة (API) | PHP 8 (REST API + جلسات + حماية CSRF) | alwaysdata |
| قاعدة البيانات | MariaDB (MySQL) | alwaysdata |
| تطبيق الجوال | Flutter | ملف APK |

- الموقع يمرّر طلبات `/api/*` إلى الخادم عبر إعداد `vercel.json`، حتى تعمل جلسة تسجيل الدخول على نفس النطاق.
- كلمات المرور تُحفظ مشفّرة، وكل طلب يغيّر البيانات محمي برمز CSRF.

## 🔌 أهم نقاط الـ API

| الوظيفة | الطلب |
|---|---|
| تسجيل الدخول / الخروج | `POST /api/auth/login` · `POST /api/auth/logout` |
| تسجيل مستفيد / مقدم خدمة | `POST /api/auth/register/beneficiary` · `POST /api/auth/register/provider` |
| المستخدم الحالي / تعديل الملف | `GET /api/auth/me` · `PUT /api/auth/profile` |
| الخدمات | `GET/POST /api/services` · `GET/PUT/DELETE /api/services/{id}` |
| الحجوزات | `GET/POST /api/bookings` · `PATCH /api/bookings/{id}/status` |
| المحادثة | `GET/POST /api/bookings/{id}/messages` |
| المفضلة | `GET/POST /api/favorites` · `DELETE /api/favorites/{serviceId}` |
| التقييمات | `GET/POST /api/ratings` |
| الإشعارات | `GET /api/notifications` · `POST /api/notifications/read` |
| تواصل معنا | `POST /api/contact` |

> أي طلب `POST` أو `PUT` أو `PATCH` أو `DELETE` يحتاج الهيدر `X-CSRF-Token` (من `GET /api/auth/csrf`) مع كوكي الجلسة.

## 🚀 التشغيل على الجهاز

**المتطلبات:** Node.js 18 أو أحدث.

1. تثبيت الحزم:
   ```bash
   npm install
   ```
2. إنشاء ملف `.env.local` في المجلد الرئيسي:
   ```
   VITE_AUTH_MODE=real
   VITE_API_URL=http://localhost:5173
   ```
   (الموقع على الجهاز يمرّر طلبات `/api` للخادم تلقائياً عبر إعداد `vite.config`)
3. التشغيل:
   ```bash
   npm run dev
   ```
4. فتح الرابط: http://localhost:5173

## ☁️ النشر

- **الموقع:** أي `git push` على فرع `main` يُنشر تلقائياً على Vercel خلال دقيقة.
- **الـ API:** يعمل على خادم alwaysdata في المجلد `~/www/php_backend`، وإعدادات الاتصال بالقاعدة في ملف `config/hosting.env` على الخادم (غير مرفوع على GitHub لأنه يحتوي كلمات سر).
- ⚠️ نسخة الـ API على الخادم فيها ملفات إضافية غير موجودة في مجلد `backend` هنا (مثل `Engagement.php` للمفضلة والتقييمات والإشعارات)، فالخادم هو المرجع.

└── utils/                # أدوات مساعدة وتنسيقات
backend/                  # كود الـ PHP API
