## 🌟 نظرة عامة على المشروع

**وصال (WISAL)** هي منصة رقمية رائدة صُممت خصيصاً لخدمة قاصدي المسجد الحرام بمكة المكرمة (من معتمرين وزوار وحجاج)، عبر ربطهم بنخبة مؤهلة وموثوقة من أبناء مكة المكرمة لتقديم الخدمات المساندة:
- **المرافقة والإرشاد المكاني:** توجيه مسارات الطواف والسعي وأوقات الهدوء.
- **مساعدة كبار السن:** توفير وتأمين الكراسي المتحركة ومرافقتهم برفق وأدب في الأدوار المخصصة.
- **الترجمة والمساعدة اللغوية:** تسهيل التواصل للزوار الناطقين بالإنجليزية، الأردية، الإندونيسية، وغيرها.
- **خدمات المساعدة والتنقل:** تسيير وتنقل العربات الكهربائية والجسور المعلقة.
- **خدمات الدعم والمساندة:** مساندة العائلات والأطفال وذوي الاحتياجات الخاصة.

## 🚀 كيفية التثبيت والتشغيل المحلي (Setup & Run)

### المتطلبات المسبقة:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث، تم التحقق على v22.13.1).
- متصفح ويب حديث.

### خطوات التشغيل:

1. **الانتقال لمجلد المشروع:**
```bash
cd c:\xampp\htdocs\WISAL_Frontend_Professional
```

2. **تثبيت الحزم (في حال عدم تثبيتها مسبقاً):**
```bash
npm install
```

3. **تشغيل خادم التطوير المحلي:**
```bash
npm run dev
```

4. **فتح المنصة في المتصفح:**
توجه إلى الرابط التالي:
👉 **[http://localhost:5173/](http://localhost:5173/)**

5. **بناء الحزمة الإنتاجية والتأكد من سلامة الكود:**
```bash
npm run build
npx tsc --noEmit
```

## 👥 الحسابات التجريبية وآلية الاستعراض السريع

توفر المنصة في الشريط العلوي **أزراراً سريعة للتبديل بين الحسابات التجريبية** دون الحاجة لإدخال بيانات:

### 1. حساب المستفيد (زائر الحرم):
- **الاسم التجريبي:** عبدالله بن أحمد الغامدي
- **رقم الجوال:** `0501234567`
- **كلمة المرور:** `123456`

### 2. حساب مقدم الخدمة:
- **الاسم التجريبي:** م. ريان بن خالد الشريف
- **رقم الجوال:** `0543219876`
- **كلمة المرور:** `123456`
- **الميزات المتاحة:** لوحة تحكم بإحصائيات حية، إدارة الخدمات المنشورة (إضافة، تعديل، حذف، استعراض)، قبول وتأكيد الحجوزات، تسجيل إتمام الخدمات، وتعديل الملف المهني.

### 3. زر إعادة ضبط البيانات (Reset Data):
موجود في الشريط العلوي لاستعادة البيانات الافتراضية الأولية متى ما رغبت في إعادة العرض التقديمي من البداية.

## 📁 الهيكلية البرمجية للمشروع (Architecture)

```text
src/
├── app/                  # إعدادات التطبيق والموجهات المركزية (routes & App)
├── assets/               # الأصول والصور
├── components/           # المكونات المشتركة وقابلة لإعادة الاستخدام
│   ├── ui/               # مكونات التصميم الذري (Button, Input, Card, Modal, Select, Badge, RatingStars)
│   ├── layout/           # الهياكل العامة (Navbar, Footer, DashboardLayout)
│   └── shared/           # بطاقات الخدمات، الحجوزات، شارات الحالة، والزخارف
├── features/             # الميزات مصنفة حسب النطاق الوظيفي
│   ├── home/             # الصفحة الرئيسية وأقسام البطل والشركاء والأسئلة
│   ├── authentication/   # شاشات الدخول، التسجيل، واختيار نوع الحساب
│   ├── services/         # سوق الخدمات ودليل البحث وتفاصيل الخدمة
│   ├── bookings/         # نافذة تدفق الحجز متعدد الخطوات
│   ├── ratings/          # نافذة تقييم الحجوزات المكتملة
│   ├── beneficiary/      # صفحات بوابة المستفيد (لوحة التحكم، الحجوزات، المفضلة، التقييمات، الملف)
│   ├── provider/         # صفحات بوابة مقدم الخدمة (لوحة التحكم، الخدمات CRUD، الحجوزات، الملف)
│   └── pages/            # الصفحات التعريفية (عن وصال، كيف تعمل، تواصل، الشروط، الخصوصية، 404)
├── data/                 # طبقة البيانات والمستودعات
│   ├── mocks/            # بذور البيانات الافتراضية وخدمة التخزين المحلي LocalStorage
│   └── repositories/     # مستودعات مجردة (auth, service, booking, rating)
├── hooks/                # الخطافات المخصصة (useAuth, useToast)
├── types/                # تعريفات TypeScript الصارمة للكيانات والحالات
├── utils/                # الأدوات المساعدة والمحددات وتنسيق العملات والتواريخ العربية
└── styles/               # الأنماط العامة لـ Tailwind CSS والتأثيرات الإسلامية
```

## 🔌 التكامل المستقبلي مع الواجهات الخلفية (Future API Integration)

صُممت المنصة وفق نمط المستودعات المجردة (`Repository Pattern`):
- `authRepository`
- `serviceRepository`
- `bookingRepository`
- `ratingRepository`

لتحويل المنصة إلى العمل مع خادم خلفي فعلي (مثل Laravel أو Node.js أو Django)، يكفي استبدال نداءات `storage` داخل هذه المستودعات بنداءات `fetch` أو `axios` الموجهة لنقاط النهاية، دون المساس بأي من الواجهات أو الشاشات أو منطق المكونات.
